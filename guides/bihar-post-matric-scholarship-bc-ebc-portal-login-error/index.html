Bihar Post Matric Scholarship BC EBC Portal Login Error: 2026 Ka Best Aur Permanent Solution

Published: 2026-05-19

Bihar ke lakho BC (Backward Class) aur EBC (Extremely Backward Class) students ke liye Post Matric Scholarship (PMS) ek bohot bada sahara hai. Lekin pichle kuch dino se jab bhi bachche form bharne ya apna status dekhne ke liye portal open kar rahe hain, toh unhein ek hi cheez pareshan kar rahi hai – Bihar Post Matric Scholarship BC EBC portal login error.

Kabhi screen par “Invalid User ID/Password” likha aata hai, toh kabhi page open hote hi “Server Error” ya white screen dikhne lagti hai. Form ki last date paas aa rahi hai aur bachche pareshan hain ki agar login hi nahi hoga toh scholarship ka paisa kaise aayega.

Portal Par Login Error Kyun Aa Raha Hai?

Mukhya roop se Bihar PMS portal (pmsonline.bih.nic.in) par login na hone ke 3 sabse bade kaaran hain:

  • Naya Portal Update (2026): Bihar sarkar ne BC-EBC portal ke database ko upgrade kiya hai taaki fake verification ko roka ja sake. Is wajah se purani login details temporary kaam nahi kar rahi hain.
  • Aadhaar-Mobile Unlinked: Agar aapka Aadhaar card aapke registered mobile number se mismatch hai, toh portal security verification fail kar deta hai.
  • Heavy Server Traffic: Ek saath lakho students jab website par aate hain, toh portal ka server “504 Gateway Timeout” ya “Object Reference Not Set” jaisa technical error dikhane lagta hai.

Bihar Post Matric Scholarship BC EBC Portal Login Error Ko Kaise Thik Karein?

Agar aapka account bhi open nahi ho raha hai, toh ghabraiye mat. Niche diye gaye steps ko dhyan se follow karein, aapka login 100% ho jayega.

Step 1: Browser Ka Cache Aur Cookies Clear Karein

Bahut baar hamare phone ke browser (jaise Google Chrome) mein purana data save rehta hai, jisse portal naye updates ko load nahi kar pata.

  1. Apne Chrome browser ki settings mein jayein.
  2. ‘Privacy and Security’ par click karein aur ‘Clear Browsing Data’ chunein.
  3. ‘All Time’ select karke cache aur cookies ko clear kar dein. Iske baad website ko fresh open karein.

Step 2: ‘Forgot User ID’ Aur ‘Password’ Option Ka Use Karein

Agar browser clear karne ke baad bhi “Invalid Credentials” dikha raha hai, toh iska matlab aapka password system se reset ho chuka hai.

  1. Portal ke student login page par niche diye gaye “Forgot User ID” par click karein.
  2. Apna Aadhaar Number aur Date of Birth enter karein.
  3. Aapke registered mobile number par ek SMS aayega jisme aapki sahi User ID hogi.
  4. Uske baad “Forgot Password” par click karke naya password generate kar lein.

Step 3: Portal Par Student Ka Identity Status Check Karein

Kai baar students ka registration department level se ‘Reject’ ya ‘Hold’ par daal diya jata hai, jis wajah se login band ho jata hai.

  • Portal ke home page par jayein aur “Verify Your Student Applications Status” par click karein.
  • Wahan apna Aadhaar number daal kar check karein ki aapka account active hai ya nahi. Agar active dikha raha hai, toh hi aap login kar payenge.

Login Hone Ke Baad Form Bharte Time In Baaton Ka Dhyaan Rakhna

Jab aapka PMS Bihar Student Login successfully ho jaye, toh naya form bharte time ye baatein yaad rakhein varna account fir se block ho sakta hai:

  • Naya Income Certificate: Bihar mein BC-EBC students ke liye parivar ki varshik aay ₹3,00,000 se kam honi chahiye. Certificate bilkul naya hona chahiye.
  • Bonafide Certificate: Apne college se current session ka hi bonafide letter sign karwa kar upload karein.
  • Bank Seeding Status: Check kar lein ki aapka bank account Aadhaar se seed (NPCI mapped) hai ya nahi, kyunki Bihar sarkar ab sirf DBT ke jariye hi paisa bhejti hai.

FAQs: Aksar Puche Jane Wale Sawal

1. “User ID not found” error dikhane par kya karein? Agar naya password mangwane par bhi ‘User ID not found’ dikhata hai, toh iska matlab aapka registration portal se remove ho gaya hai ya reject ho gaya hai. Aise mein aapko naye sire se ‘New Student Registration’ karna pad sakta hai.

2. Kya mobile number kho jaane par login ho sakta hai? Agar aapka purana mobile number band ho gaya hai, toh aapko portal ke helpdesk par mail karna hoga ya fir ‘Update Mobile Number’ ka link active hone ka wait karna hoga, kyunki OTP ke bina login mumkin nahi hai.

3. BC EBC portal par login error “Under Maintenance” dikhaye toh kya karein? Jab bhi portal par ‘Under Maintenance’ likha aaye, toh iska matlab piche se technical team kaam kar rahi hai. Isme aapko kuch nahi karna hai, bas 24 se 48 ghante ka intezar karna hai.

4. Kya main direct cyber cafe se hi form thik karwa sakta hoon? Cyber cafe se aap form bharwa sakte hain, lekin yaad rakhein ki login password hamesha apne paas hi save rakhein, kyunki agle saal renewal ke waqt iski fir se jarurat padegi.

5. Bihar Post Matric Scholarship ka paisa kab tak aata hai? Login error thik hone aur form final submit hone ke baad, pehle college verify karta hai aur fir jila (district) level se approval milta hai. Is poore process mein 3 se 4 mahine lag jaate hain.
